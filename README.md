# Telegram-бот для выдачи номеров

Бот реагирует на точное сообщение `Вотс` только от одного указанного пользователя, только в заданной группе и теме. Он отправляет один номер в ту же тему и сразу удаляет его из очереди. Одновременные запросы не могут получить один и тот же номер.

Есть две очереди:

- **на перестановку** — выдаётся первой;
- **обычная** — выдаётся после неё.

Номера добавляются в личном чате с ботом через кнопки. Там же можно посмотреть остаток, первые 20 номеров каждой очереди и общее число выдач. История выдач хранится в `data/phones.db`.

## 1. Создание бота

1. Открой в Telegram `@BotFather`, выполни `/newbot` и сохрани токен.
2. В `@BotFather` выполни `/setprivacy`, выбери своего бота и нажми **Disable**. Без этого бот не увидит обычное сообщение `Вотс`.
3. Добавь бота в закрытую группу. Дай ему право отправлять сообщения.

## 2. Установка на Windows

1. Установи [Python 3.11 или новее](https://www.python.org/downloads/). При установке включи **Add Python to PATH**.
2. Распакуй проект в `C:\Users\wofll\Projects\whatsapp-phone-bot`.
3. Дважды нажми `setup.bat`.
4. Открой созданный файл `.env` и вставь токен после `BOT_TOKEN=`.

## 3. Получение Telegram ID

1. После добавления токена запусти `discover_ids.bat`.
2. Нужный пользователь должен отправить любое сообщение в нужной теме группы.
3. В окне появятся `GROUP_ID`, `TOPIC_ID` и `REQUESTER_ID`. Скопируй их в `.env`.
4. В `ADMIN_IDS` укажи свой Telegram ID. Можно перечислить несколько ID через запятую.
5. Останови поиск сочетанием `Ctrl+C`. Одновременно `discover_ids.bat` и основной бот запускать нельзя.

Пример готового `.env`:

```env
BOT_TOKEN=1234567890:секретный_токен
GROUP_ID=-1001234567890
TOPIC_ID=123
REQUESTER_ID=123456789
ADMIN_IDS=987654321
DATABASE_PATH=data/phones.db
```

Никому не отправляй файл `.env` и токен бота.

## 4. Запуск и работа

1. Запусти `start.bat` и не закрывай окно: бот работает, пока запущен этот процесс и включён ПК.
2. Напиши боту `/start` в личном чате. Кнопками добавь номера, каждый с новой строки.
3. Когда закреплённый пользователь напишет `Вотс` в настроенной теме, бот отправит следующий номер. В других чатах, темах и для других пользователей запрос будет молча проигнорирован.

Чтобы бот запускался вместе с Windows, добавь ярлык `start.bat` в папку автозагрузки (`Win+R` → `shell:startup`). Для круглосуточной работы ПК должен оставаться включённым и подключённым к интернету.
