# Telegram userbot для выдачи номеров

Программа работает через твой личный Telegram-аккаунт: отдельного бота создавать и добавлять в группу не нужно. Она реагирует на точное сообщение `Вотс` только от одного закреплённого `REQUESTER_ID`, только в заданной закрытой группе и теме. Это может быть ID другого человека или твой собственный ID для проверки. Ответ отправляется от твоего аккаунта прямо на сообщение-запрос.

Номер сразу удаляется из очереди. Одновременные запросы не могут получить один номер дважды. Очередь **на перестановку** выдаётся раньше обычной.

## Безопасность

- Никому не отправляй `API_HASH`, код входа, пароль 2FA, файл `.env` и файл `data/user.session`.
- Файл `user.session` даёт доступ к Telegram-аккаунту почти как активный сеанс. Не загружай его в облако и не пересылай.
- Если API-данные попали на скриншот или в переписку, не используй их: выпусти новые на `my.telegram.org`.
- Автоматизация личного аккаунта может подпадать под ограничения Telegram. Не используй программу для спама или массовой рассылки.

## 1. Установка на Windows

1. Установи именно [Python 3.12 (64-bit)](https://www.python.org/downloads/release/python-31210/). **Python Launcher** лучше включить, но новый установщик также найдёт стандартную установку без него.
2. Распакуй проект, например, в `C:\Users\wofll\Projects\telegram-phone-userbot`.
3. Запусти `setup.bat`. Он создаст окружение и файл `.env`.
4. Запусти `configure.bat` и введи **новые** `API_ID` и `API_HASH` из раздела Apps на `my.telegram.org`. При вводе `API_HASH` символы специально не показываются. Настройки сохранятся в `.env` именно текущей папки.

Пока оставь остальные ID пустыми:

```env
API_ID=
API_HASH=твой_новый_api_hash
GROUP_ID=
TOPIC_ID=
REQUESTER_ID=
DATABASE_PATH=data/phones.db
SESSION_PATH=data/user
```

## 2. Первый вход и получение ID

1. Запусти `discover_ids.bat`.
2. При первом запуске введи номер телефона своего Telegram-аккаунта, код входа из Telegram и, если включён, пароль 2FA. Эти данные обрабатываются Telethon локально и не сохраняются в проекте; сохраняется только локальная сессия.
3. Выбери по номеру закрытую группу, затем нужную тему и человека среди авторов последних сообщений.
4. Подтверди автоматическую запись найденных ID в `.env`.

Скрипт только читает доступную аккаунту историю и ничего не отправляет. Он работает и для закрытой темы, если старые сообщения по-прежнему видны.

Аккаунт, под которым выполнен вход, уже должен состоять в этой группе и иметь право писать в теме.

## 3. Добавление номеров

Запусти `manage.bat`. Откроется локальное окно управления:

- вставь номера по одному на строке;
- нажми **Добавить обычные** или **Добавить на перестановку**;
- при необходимости перемещай и удаляй выбранные номера;
- сверху отображается остаток и число выдач.

Это локальные кнопки на ПК. Telegram не разрешает личному аккаунту отправлять бот-клавиатуры, поэтому управление очередью вынесено в отдельное безопасное окно.

## 4. Запуск

Запусти `start.bat` и оставь окно открытым. Когда закреплённый пользователь отправит `Вотс` в настроенной теме, программа сразу ответит следующим номером от твоего аккаунта. Другие пользователи, чаты, темы и тексты игнорируются.

Для проверки выбери себя среди авторов в `discover_ids.bat` или временно поставь свой Telegram ID в `REQUESTER_ID`. Тогда userbot обработает твоё собственное сообщение `Вотс`. После теста замени `REQUESTER_ID` на ID единственного нужного человека — два ID одновременно программа не принимает.

`manage.bat` можно держать открытым одновременно со `start.bat`. Чтобы userbot работал круглосуточно, ПК должен оставаться включённым и подключённым к интернету.

Для автоматического запуска создай ярлык `start.bat` в папке автозагрузки: `Win+R` → `shell:startup`.
